      Audit de sécurité
      Avant d'installer une ressource ou d'ouvrir un serveur, je lis le code et je cherche ce qui peut être exploité ou ce qui a été planqué dedans. Ensuite je corrige.
      01
      Backdoors
      Code obfusqué, décodeurs XOR, exécution distante, fichiers aux noms camouflés, lignes cachées au fond des manifests.
      02
      Events réseau
      Tout ce qu'un menu de triche peut déclencher : argent, items, munitions, poids. Je valide, je plafonne, je limite le débit.
      03
      Anti-triche serveur
      Noclip, vitesse, téléportation, soin, godmode, spam d'entités. Détecté côté serveur, donc impossible à désactiver depuis le client.

      Une base FiveM ESX qui se réinfectait toute seule après chaque nettoyage. Le coupable était un faux module système planqué en dehors du dossier des ressources, qui réinjectait tout au démarrage. Trouvé en coupant le serveur par moitiés jusqu'à l'isoler. Derrière : faille de munitions infinies corrigée et events sensibles verrouillés.
